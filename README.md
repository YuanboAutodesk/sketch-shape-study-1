# Shape rating study

A short study: you see a hand sketch and two 3D shapes built from it, and rate each shape
from 1 to 5 on details, proportion and fidelity. 15 sketches, about 15 minutes.

**Take it:** https://YuanboAutodesk.github.io/sketch-shape-study-1/

Your answers stay in your browser. At the end you download a JSON file and send it back to
whoever invited you -- nothing is uploaded anywhere.
